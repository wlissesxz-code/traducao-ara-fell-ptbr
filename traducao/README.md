# Catálogo português

Os arquivos em `partes/` formam um único catálogo de chaves e traduções. Estão divididos para facilitar revisão e publicação. Nenhuma chave se repete entre as partes. O ZIP da release inclui também `pt-BR.json` com o catálogo completo.

Para propor correções, procure a frase em `partes/` e abra um pull request com a alteração. Corrija apenas o texto; preserve chaves, códigos de cor, variáveis e pausas. Uma alteração no catálogo precisa ser integrada ao pacote Unity e a uma nova release para aparecer no jogo.
